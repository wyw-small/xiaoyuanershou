# REST API 接口文档

基础地址：`http://127.0.0.1:3000`

除注册、登录、公开列表外，受保护接口需要请求头：

```http
Authorization: Bearer <token>
Content-Type: application/json
```

## 公开接口

| 方法 | 地址 | 说明 |
|---|---|---|
| GET | `/api/health` | 服务健康检查 |
| GET | `/api/stats` | 公开统计数据 |
| POST | `/api/auth/register` | 注册学生账号 |
| POST | `/api/auth/login` | 登录 |
| GET | `/api/market` | 搜索、分类和分页获取已审核商品 |
| GET | `/api/market/:id` | 获取商品详情 |
| GET | `/api/lostfound` | 搜索、分类和分页获取已审核失物信息 |
| GET | `/api/lostfound/:id` | 获取失物信息详情 |

列表接口支持参数：`q`、`category`、`status`、`sort`、`page`、`pageSize`。

## 登录用户接口

| 方法 | 地址 | 说明 |
|---|---|---|
| GET | `/api/auth/me` | 获取当前用户 |
| POST | `/api/market` | 发布二手商品 |
| PUT | `/api/market/:id` | 修改商品，修改后重新进入待审 |
| DELETE | `/api/market/:id` | 删除自己发布的商品 |
| POST | `/api/market/:id/favorite` | 收藏/取消收藏商品 |
| DELETE | `/api/market/:id/favorite` | 取消收藏商品 |
| POST | `/api/lostfound` | 发布失物招领 |
| PUT | `/api/lostfound/:id` | 修改失物招领 |
| DELETE | `/api/lostfound/:id` | 删除自己发布的失物招领 |
| GET | `/api/market?mine=1` | 获取自己的商品 |
| GET | `/api/lostfound?mine=1` | 获取自己的失物信息 |

## 管理员接口

| 方法 | 地址 | 说明 |
|---|---|---|
| GET | `/api/admin/stats` | 获取管理统计 |
| GET | `/api/admin/pending` | 获取待审核内容 |
| PATCH | `/api/admin/market/:id/review` | 审核二手商品 |
| PATCH | `/api/admin/lostfound/:id/review` | 审核失物招领 |

审核请求体：

```json
{
  "status": "approved",
  "reason": ""
}
```

驳回时 `status` 为 `rejected`，`reason` 必填。

## 错误响应

```json
{
  "ok": false,
  "message": "错误说明"
}
```

常见状态码：`400` 参数错误、`401` 未登录、`403` 权限不足、`404` 数据不存在、`405` 方法不支持。
