# 数据库设计说明

系统原型使用 JSON 文件持久化，逻辑结构可一一映射到关系数据库。生产环境建议使用 MySQL 8.0，并将 JSON 数组转换为下列数据表。

## 1. 用户表 user

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键，自增 |
| username | varchar(20) | 登录名，唯一索引 |
| display_name | varchar(20) | 显示姓名或昵称 |
| role | varchar(10) | student/admin |
| salt | varchar(32) | 密码盐 |
| password_hash | varchar(128) | scrypt 哈希 |
| created_at | datetime | 创建时间 |

## 2. 二手商品表 market_item

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| owner_id | bigint | 发布人，外键 user.id |
| title | varchar(50) | 商品标题 |
| description | varchar(1000) | 商品描述 |
| price | decimal(10,2) | 价格 |
| category | varchar(30) | 分类 |
| condition_text | varchar(20) | 成色 |
| contact | varchar(80) | 联系方式 |
| trade_place | varchar(80) | 交易地点 |
| status | varchar(20) | pending/approved/rejected/sold |
| review_reason | varchar(100) | 驳回原因 |
| reviewer_id | bigint | 审核人 |
| reviewed_at | datetime | 审核时间 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

索引建议：`owner_id`、`status`、`category`、`created_at` 普通索引，`title` 可建立全文索引。

## 3. 失物招领表 lost_found

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| owner_id | bigint | 发布人 |
| kind | varchar(10) | lost/found |
| title | varchar(50) | 标题 |
| description | varchar(1000) | 描述 |
| category | varchar(30) | 物品分类 |
| location | varchar(80) | 地点 |
| event_date | date | 发生日期 |
| contact | varchar(80) | 联系方式 |
| status | varchar(20) | pending/approved/rejected/closed |
| review_reason | varchar(100) | 驳回原因 |
| reviewer_id | bigint | 审核人 |
| reviewed_at | datetime | 审核时间 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

## 4. 收藏表 favorite

| 字段 | 类型 | 说明 |
|---|---|---|
| id | bigint | 主键 |
| user_id | bigint | 用户 |
| target_type | varchar(20) | market/lostfound |
| target_id | bigint | 目标内容编号 |
| created_at | datetime | 收藏时间 |

唯一索引建议：`(user_id, target_type, target_id)`。

## 5. 实体关系

- user 1:N market_item
- user 1:N lost_found
- user 1:N favorite
- market_item 1:N favorite（逻辑关联）
- lost_found 1:N favorite（逻辑关联）

审核字段通过 reviewer_id 与 user 表形成逻辑外键；删除用户时建议保留历史发布记录或将 owner_id 设为 NULL。
